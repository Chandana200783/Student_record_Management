# Student Record Management System

## Objective
To develop a Python application that manages student records using CRUD operations and JSON file storage.

## Features
- Add new student records
- View all students
- Search students by roll number or name
- Update student details
- Delete student records
- Validate email addresses and GPA values
- Prevent duplicate roll numbers
- Store records permanently using JSON
- Handle invalid inputs and file errors

## Technologies Used
- Python 3
- JSON
- Regular Expressions
- File Handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python student_management.py`

## Data Storage
Student records are saved in `students.json`.

## Testing
Tested adding, viewing, searching, updating, and deleting student records, along with input validation.
